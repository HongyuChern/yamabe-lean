# Third-party source modifications

These entries identify Lean code retained or adapted in the Yamabe3 sources.
The direct source files are from PoincareLib in the [pinned dependency](https://github.com/frenzymath/PoincareConjecture/tree/62db01af9388dc1d9b56b66d6674f4c09b2318a2/PoincareLib).
The corresponding files are byte-identical to those in the
[original PoincareLib distribution](https://github.com/frenzymath/Poincare-Conjecture/blob/432c38f2aa5a30efb13871292d17b4a3309a496a/README.md), which supplies
the [Apache-2.0 grant](https://github.com/frenzymath/Poincare-Conjecture/blob/432c38f2aa5a30efb13871292d17b4a3309a496a/LICENSE).
File headers retain the applicable notices and describe the local changes.
DifferentialGeometry is credited where the direct source documents that earlier lineage.
